# Third-party assets

## Player character — `weaver.glb`

* **KayKit — Adventurers Character Pack 1.0**
* Author: Kay Lousberg (www.kaylousberg.com)
* Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
* Licence: **CC0 1.0 Universal** — https://creativecommons.org/publicdomain/zero/1.0/
* Used: the `Mage` model, re-exported with a reduced clip set and a downsampled
  atlas by `tools/blender/adopt_character.py`.

CC0 is a public-domain dedication: commercial use is permitted and attribution
is not required. It is credited here anyway, as good practice and because it
makes the provenance of a shipped binary obvious.

Modifications made: 71 of 76 animation clips removed (kept `Idle`, `Walking_A`,
`Running_A`, `Running_Strafe_Left`, `Running_Strafe_Right`), texture atlas
downsampled from 1024px to 256px, re-exported as a single GLB (3.5 MB → 478 KB).

## World props — `props.glb`

* **KayKit — Prototype Bits 1.0**
* Author: Kay Lousberg (www.kaylousberg.com)
* Source: https://github.com/KayKit-Game-Assets/KayKit-Prototype-Bits-1.0
* Licence: **CC0 1.0 Universal** — https://creativecommons.org/publicdomain/zero/1.0/
* Used: 14 props — pillars, wall segments, stairs, barrels, crates, pallets,
  cans, worktables and beams — merged into a single GLB by
  `tools/blender/adopt_props.py`.

Modifications made: the texture atlas was downsampled from 1024px to 512px, and
the fourteen models were re-exported into one file (1.95k triangles, 134 KB).
Grounding is applied at load time in `src/world/Props.tsx` rather than in the
file, because the glTF exporter does not carry a per-prop offset through to the
node transform. Each prop becomes an instanced mesh, so the ~180 placed objects
cost one draw call per prop type.

## Everything else

All remaining models — the Synthesis Tree, the tapestry, the puzzle console and
the seven region landmarks — are original and generated by
`tools/blender/build_assets.py`. No third-party assets, no textures, no audio
files. All audio is synthesised at runtime with the Web Audio API.
